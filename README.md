The funniest one-star review of the Moon in 120 characters or fewer: a
disappointed reviewer complains that the Moon follows them home every night,
stares through the window, and has never once paid rent.

## Run it

```sh
node main.ts
```

`main.ts` writes the single review line to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(`entry.txt` in `/output` by default). Deterministic: no clock, no random
input, no network — the same line every run.
